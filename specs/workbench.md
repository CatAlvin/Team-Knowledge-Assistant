# 前端工作台

## TK-UI01 工作台

现有 FastAPI 直接提供根路径页面和 /assets/ 静态资源，不增加独立业务服务。页面按概览、消息记录、行动项、知识问答组织。快照日期、数据量及分布来自 /workspace。

## TK-UI02 接口

- GET /workspace：当前数据、任务、风险、来源清单与工作台配置。
- POST /workspace/brief：按当前消息快照生成完整结构化简报。共享请求包含 days（1 至 90），团队项目采用整份快照。
- POST /workspace/ask：输入 question 长度 3 至 2000；返回 answer、sources 和 refused。
- GET /workspace/documents/{name}：仅访问项目知识库中列出的 Markdown 文件，返回正文。
- / 和 /assets/ 提供公开界面；配置 SERVICE_API_KEY 后，业务接口仍验证 Bearer 令牌。

模型调用仅由明确的生成或问答操作触发。页面初次加载不调用模型。截图与功能验证使用 offline。

## TK-UI03 状态与展示

搜索、状态筛选、空结果、读取失败与重试、生成中反馈均须可操作。消息详情按纯文本展示；知识回答与来源支持标题、列表和代码排版，源 HTML 转义，链接仅允许 HTTP(S)。知识问答失败时给出可重试提示，资料无匹配时引导重新提问。

行动项完成状态在当前浏览器持久化，按任务内容区分，不改变后端任务记录。导出包括对应 review_state。

## 验收

- TK-UI-AC01：页面可加载，所有可见控件有实际行为。
- TK-UI-AC02：搜索与筛选结果来自当前数据，导出内容与当前项目一致。
- TK-UI-AC03：相关问答可打开来源，无关问题显示重新提问入口。
- TK-UI-AC04：深浅主题、键盘操作、移动布局和详情关闭通过浏览器检查。
- TK-UI-AC05：现有业务回归及接口契约检查继续通过，压缩包包含静态资源。
